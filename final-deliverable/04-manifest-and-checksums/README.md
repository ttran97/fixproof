# Manifest and checksums placeholder

At final packaging time, create a machine-readable manifest and a readable
file index containing:

- final relative path;
- purpose;
- source path or source repository;
- file size;
- SHA-256 hash;
- generation or approval date;
- validation status;
- whether the file is required or optional supporting material.

Also record:

- source commit or release tag;
- final public URL;
- final presentation URL or filename;
- clean reproduction date and result;
- project test count;
- known limitations.

Do not generate final hashes until the approved artifacts have stopped
changing.
