# Source-code placeholder

## Planned access method

Record one instructor-accessible source location:

- public or Georgia Tech-accessible GitHub repository; or
- a OneDrive, Google Drive, or Georgia Tech storage link that does not require
  the instructional staff to request permission.

The final entry should identify:

- repository or archive URL;
- release tag or commit identifier;
- license or coursework-use notice;
- supported Python and Node.js versions;
- entry points for verification;
- directories intentionally excluded from the release.

Do not publish **.env**, API keys, local environments, caches, temporary
workspaces, Office lock files, debug logs, or unreviewed raw artifacts.
