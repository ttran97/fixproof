# Final submission checklist

## Final report

- [ ] The body is self-contained and within the applicable page limit.
- [ ] The methodology, analysis, results, limitations, and conclusion do not
      depend on opening supporting files.
- [ ] Candidate-level and observation-level denominators are labeled.
- [ ] Primary-v1, supplemental-v1, and later extensions remain separate.
- [ ] Every citation and external link was opened and verified.
- [ ] The AI-use disclosure is complete and personally reviewed.
- [ ] DOCX and PDF page breaks, tables, figures, fonts, and links were checked.

## Final presentation

- [ ] The recording is no longer than 15 minutes.
- [ ] Slides are readable at normal playback resolution.
- [ ] The presentation demonstrates only the most useful supporting artifacts.
- [ ] A clear supporting-materials link is provided to the instructional team.
- [ ] The presentation URL or file works without requesting access.

## Supporting materials

- [ ] Source code, workbook, evidence appendix, scripts, datasets, and
      documentation are organized and indexed.
- [ ] The clean-package reproduction rehearsal passed.
- [ ] The public dashboard, test-evidence page, workbook, and appendix work.
- [ ] Sharing permissions were tested in an incognito/private browser.
- [ ] No credentials, local-user paths, environments, caches, temporary files,
      Office lock files, browser profiles, or debug logs are included.
- [ ] The final manifest and SHA-256 checksums match the delivered files.

## Submission records

- [ ] Final Report submission receipt saved.
- [ ] Final Presentation submission receipt saved.
- [ ] Final supporting-materials URL recorded.
- [ ] Final source release tag or commit recorded.
- [ ] A local archival copy of the exact submitted package retained.
